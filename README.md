# فلك

تطبيق فلكي بحسابات المكتبة السويسرية الأصلية، تعمل داخل الهاتف بلا إنترنت.

الرخصة: الرخصة العامة المفتوحة (الإصدار الثالث أو أحدث)، انظر ملف الرخصة.

---

## الحالة

- المحرّك منجز ومختبر على الحاسوب (التفاصيل في `docs/engine.md`).
- هيكل تطبيق الأندرويد منجز، والمحرّك مربوط به.
- عند أول تشغيل ينسخ التطبيق ملفات الجداول إلى ذاكرة الهاتف، ويعيد نسخها بعد كل تحديث.
- الشاشة الحالية شاشة فحص: تعرض مواقع الكواكب الآن فوق بغداد، أو سبب الفشل بوضوح.

## الحصول على ملف التثبيت

كل رفع إلى المستودع يشغّل البناء التلقائي على خوادم غيت هب.
الملف يظهر في صفحة البناء ضمن قسم الملفات الناتجة باسم:

```
falak-release-apk
```

الملف موقَّع بمفتاح التطوير، يصلح للتجربة على الهاتف فقط، وليس للنشر في المتجر.

## البناء على الحاسوب

```bash
npm ci
cd android && ./gradlew assembleRelease
```

## محتوى المستودع

```
App.tsx                         شاشة الفحص
specs/NativeAstroEngine.ts      تعريف الوحدة الأصلية
shared/                         المحرّك والمكتبة السويسرية
src/astro/engine.ts             الواجهة التي تستخدمها الشاشات
assets/ephe/                    ملفات الجداول من 1800 إلى 2400
android/app/src/main/jni/       ربط المحرّك بالأندرويد
android/.../EphemerisInstaller.kt   تثبيت ملفات الجداول عند أول تشغيل
ios/Falak/NativeAstroEngineProvider.*   ربط المحرّك بالآيفون (لم يُبنَ بعد)
tests/                          اختبارات الدقة على الحاسوب
.github/workflows/android.yml   البناء التلقائي
```
