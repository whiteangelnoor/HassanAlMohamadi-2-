# فلك

تطبيق فلكي بحسابات المكتبة السويسرية الأصلية، تعمل داخل الهاتف بلا إنترنت.

الرخصة: الرخصة العامة المفتوحة (الإصدار الثالث أو أحدث)، انظر ملف الرخصة.

---

## الحالة

- المحرّك منجز ومختبر على الحاسوب (التفاصيل في `docs/engine.md`).
- هيكل تطبيق الأندرويد منجز، والمحرّك مربوط به.
- عند أول تشغيل ينسخ التطبيق ملفات الجداول إلى ذاكرة الهاتف، ويعيد نسخها بعد كل تحديث.
- إدخال بيانات الولادة: التاريخ والوقت ومكان الولادة، مع بحث عن المدن بالعربية والإنكليزية.
- تحويل التوقيت المحلي التاريخي إلى العالمي من جداول المناطق الزمنية الرسمية، مع التوقيت الصيفي، ومع التوقيت الشمسي لمكان الولادة قبل اعتماد التوقيت الرسمي.
- شاشة الخريطة: مواقع الكواكب، والبيت الذي يقع فيه كل كوكب، والطالع، ووسط السماء، ورؤوس البيوت.

## مصادر البيانات

قاعدة المدن مأخوذة من مشروع الأسماء الجغرافية المفتوح (الرخصة الحرة مع ذكر المصدر)، وتشمل المدن التي يزيد سكانها على خمسة آلاف.
جداول المناطق الزمنية من قاعدة المناطق الزمنية الرسمية (ملكية عامة).
أسماء الدول بالعربية من حزمة أسماء الدول المفتوحة.

```
GeoNames (CC BY 4.0)
IANA tz database 2026e
i18n-iso-countries (MIT)
```

لإعادة توليد البيانات: `tools/build_geodata.py`.

## الحصول على ملف التثبيت

كل رفع إلى المستودع يشغّل البناء التلقائي على خوادم غيت هب.
الملف يظهر في صفحة البناء ضمن قسم الملفات الناتجة باسم:

```
falak-release-apk
```

الملف موقَّع بمفتاح التطوير، يصلح للتجربة على الهاتف فقط، وليس للنشر في المتجر.

## البناء على الحاسوب

```bash
npm ci
cd android && ./gradlew assembleRelease
```

```
tests/                          اختبارات الدقة على الحاسوب

```
